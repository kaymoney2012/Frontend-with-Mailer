# Front-End

## Stack

- React + TypeScript
- Redux Toolkit for the auth token
- Axios for API calls
- Tailwind CSS for styling
- React Toastify for notifications

## Pages

- `/` and `/login`
- `/register`
- `/otp`
- `/dashboard` (protected)

## Run it

```
npm install
npm run dev
```

Set your backend URL in `.env`:

```
VITE_APP_API_URL=https://your-backend-url/
```
